## 三、功能概览

- 语音翻译: 点一下麦克风说话，说完自动断句出结果，识别是流式的、边说边出字。
- 对话模式: 面对面对话场景，双方语言一键对调，说完一句自动进入下一句。
- 文本翻译: 嘈杂环境或需要精确表达时用键盘输入，结果可朗读、可复制。
- 常用短语: 内置分类短语本，表冠切换分类，点一下即朗读。
- 历史记录: 本地保存，不上传。

## 四、交互设计

- 表冠优先: 切换板块、切换短语分类、调音量都可用旋转表冠完成，不依赖精细触控。
- 弧形排布: 圆形屏上正文沿弧带铺开，吃满弧面空间，而不是硬套矩形布局。
- 自动断句: 靠端点检测判断「说完了」，避开小屏停止按钮难点准的问题。
- 状态可感知: 引擎状态如实显示，不静默失败。本地语音包缺失时直接提示改用键盘，而不是点了没反应。
- 双形态自适应: 圆形屏与方形屏各一套布局，运行时按屏幕形状自动切换。

## 五、技术方案

- 语音识别: sherpa-onnx + Zipformer 流式模型，中英双语，int8 量化。
- 机器翻译: 双档可切换。快速档为 ML Kit 端侧翻译；高精度档为 OPUS-MT + ONNX Runtime。
- 语音合成: 系统 TTS 引擎，复用设备已装离线语音包，语速可调。
- 界面: Jetpack Compose。

## 六、安装

方式一，用 adb 安装（推荐，手表与电脑在同一网络或已用 USB 连接）:

```
adb install -r watch-translate-v1.0.32.apk
```

若手表上已装有更高版本号的包，需要降级安装时加 `-d`:

```
adb install -r -d watch-translate-v1.0.32.apk
```

方式二，把 APK 传到手表后用文件管理器点击安装。首次安装会提示授予麦克风权限，语音翻译必须有此权限，文本翻译与短语页不受影响。

校验文件完整性（Windows）:

```
certutil -hashfile watch-translate-v1.0.32.apk SHA256
```

macOS / Linux:

```
sha256sum watch-translate-v1.0.32.apk
```

输出应与上文「SHA-256」一行的值完全一致。

## 七、首次使用须知

- 空间占用: APK 约 497 MB，安装后首次启动会把离线模型解压到应用私有目录，建议预留 1 GB 以上可用空间。
- 首次启动: 解压需要一些时间，取决于手表存储性能，期间请勿强制关闭应用。解压只在首次进行，之后常驻复用。
- 模型不做二次压缩: 打包时已对 `.onnx` 等模型文件关闭压缩，以缩短构建与首次解压耗时。

## 八、关于「离线」的边界

语音识别、翻译推理、语音合成本身全部离线，翻译内容不离开设备。

唯一需要联网的是「快速档」ML Kit 语言包的首次下载，约 44 MB，中英双向共用，下载完成后即完全离线推理。如果只使用高精度档，则连这一步都不需要。

声明的权限中，INTERNET 与 ACCESS_NETWORK_STATE 仅用于这一次语言包下载，不用于传输任何翻译文本；RECORD_AUDIO 用于语音输入；VIBRATE 与 WAKE_LOCK 用于提示反馈与识别期间保持唤醒。

## 九、已知问题

- 仅支持 arm64-v8a 与 armeabi-v7a 两种架构，x86 / x86_64 模拟器不可安装（为控制体积，未打包对应原生库）。
- 不支持 Wear OS 专属能力，但也不依赖它：手表相关特性均以 `required="false"` 声明，因此可装在 Wear OS 手表、OPPO Watch 等 Android 手表，甚至手机上调试运行。
- 高精度档翻译质量优于快速档，但推理更慢、占用更高，低端设备上建议留在快速档。
